S01E01 Programowanie interakcji z modelem językowym

Podstawy pracy z API modelu: wieloturowe rozmowy, strukturyzowane wyjścia JSON i weryfikacja faktów przez web search.

Otwórz lekcję S01E01
📁 01_01_grounding
Grounding — weryfikacja faktów w notatkach
Zamienia notatki Markdown na interaktywny HTML. Wyciąga koncepcje, deduplikuje synonimy, wyszukuje każdą koncepcję w internecie i dołącza źródła jako tooltips. Przykład użycia web search do grounded outputs.
structured outputs web search grounding HTML
$ npm run lesson1:grounding

Multi-turn — konwersacja z historią
Demonstracja wieloturowej rozmowy przez Responses API z pełną historią wiadomości. Model odpowiada na pytanie i kontynuuje w kolejnym turnie, korzystając z poprzedniego kontekstu. Pokazuje licznik tokenów reasoning.
multi-turn conversation history Responses API
$ npm run lesson1:interaction
📁 01_01_structured
Structured Outputs — gwarantowany JSON
Model zwraca obiekt JSON zgodny ze ściśle zdefiniowanym schematem (strict: true). Przykład ekstrahowania danych osobowych (imię, wiek, zawód, umiejętności) z tekstu naturalnego.
JSON schema structured outputs data extraction

S01E03 Projektowanie API — MCP

Model Context Protocol (MCP) — standardowy protokół łączenia modeli z zewnętrznymi narzędziami, zasobami i promptami.

Otwórz lekcję S01E03
📁 01_03_mcp_core
MCP Core — narzędzia, zasoby, prompty
Rdzeń protokołu MCP przez stdio: tools (calculate, summarize_with_confirmation), resources (statyczny config, dynamiczne statystyki) oraz prompts (code-review template). Demonstracja elicitation i sampling.
MCP tools resources prompts elicitation
$ npm run lesson3:mcp_core
📁 01_03_mcp_native
MCP + native — oba typy narzędzi razem
Jeden agent używa jednocześnie narzędzi MCP (pogoda, czas) i natywnych function tools (kalkulator, uppercase). In-memory serwer MCP. Pokazuje jak mieszać dwa typy narzędzi w jednej pętli agenta.
MCP native tools hybrid toolset
$ npm run lesson3:mcp_native
📁 01_03_mcp_translator
MCP Translator — agent tłumaczący pliki
Agent obserwuje folder workspace/translate/ i zapisuje angielskie tłumaczenia do workspace/translated/. Serwer REST: POST /api/translate i POST /api/chat. Narzędzia files-mcp: read, search, write, manage.
MCP file watcher REST API translation
$ npm run lesson3:mcp_translator
📁 01_03_upload_mcp
MCP Upload — lokalny + zdalny serwer MCP
Upload asystent łączący lokalny files-mcp (stdio) z zdalnym serwerem MCP (http). Listuje pliki w workspace/, uploaduje nowe i zapisuje wyniki do uploaded.md. Wymaga skonfigurowania URL zdalnego serwera w mcp.json.
MCP remote MCP file upload stdio + http

Porównanie 4 strategii chunkingu na tym samym tekście: characters (stałe okna), separators (nagłówki/paragrafy), context (fragment + LLM prefix) i topics (LLM wyznacza granice tematyczne). Wyniki jako JSONL.

Jak rozwijać Instrukcje dodawania nowych lekcji

Ta strona jest ręcznie utrzymywana. Poniżej znajdują się kroki potrzebne do dodania kolejnej sesji lub folderu.

01
Dodaj plik lekcji

Skopiuj plik lekcji Markdown do folderu ../lekcje/. Nazwa pliku powinna trzymać konwencję sXXeYY-tytuł-lekcji-ID.md.

02
Utwórz folder z przykładem

Nowy folder przykładu nazwijmy wg wzorca 0X_0Y_nazwaprzykladu, np. 02_04_something. Dodaj README.md z opisem: co robi, jak uruchomić, jakie narzędzia.

03
Dodaj sekcję do index.html

Skopiuj blok <section class="lesson-section s0X" id="sXXeYY">. Dostosuj:

  • id — np. s02e04
  • session-badge — np. S02E04
  • session-title — tytuł lekcji po polsku
  • session-desc — 1–2 zdania o czym jest lekcja
  • href w lesson-link — ścieżka do pliku .md
04
Dodaj kartę folderu

Wewnątrz nowej sekcji dodaj <div class="card">. Wypełnij: card-folder (nazwa folderu), card-title (krótki tytuł), card-desc (2–3 zdania co robi), card-tags (technologie), card-run (komenda npm/bun).

05
Kolor nowej sesji (S03+)

Dla S03 dodaj nową zmienną CSS, np. --s03-hue: 35 i użyj jej tak samo jak s01 czy s02. Dodaj odpowiednie klasy CSS. Linki nawigacyjne dodaj w <nav>.

06
Nawigacja — dodaj link

Dodaj w sekcji <nav> nowy element: <a href="#s02e04" class="s02">S02E04</a>. Klasa (s01, s02…) determinuje kolor zgodny z sesją.
